v0. Black, glass, two tabs and a plus.

Contacts stay the source of truth for who. TouchTips owns when and where. Everything runs on the phone. No server, no faces, no calendar, no email. Five surfaces.

exact · added from the app or set by you witnessed · a visit contained the add inferred · nearest visit within 2h date only before TouchTips · no date
  • Pure black. Color.black everywhere, white type, secondary at 58 percent. No greys as surfaces. Surfaces are glass or nothing.
  • Clear glass on every component. Tab bar, plus button, toolbar buttons, avatars, chips, cards, sheets: .glassEffect(.clear, in: …). Over solid black, clear glass reads as an edge highlight and a faint lift. That is the look. If a surface disappears, switch that one to .regular; it is one token.
  • Type does the work. SF Pro Display bold with tight tracking for titles and dates. Instrument Serif Italic for one word per screen: the tab title, the hero weekday, the onboarding headline. No icons where a word will do.
  • Confidence is a dot, never a colour. Fill and stroke encode the tier. The whole app is monochrome.
  • Two tabs, one action. People and Map. The plus lives in the tab bar's right-side slot using the search-role trick, so it is native glass and minimises with the bar.
  • Lists are bare. No inset cards, no backgrounds on rows. Hairline separators at 12 percent. One glass card on the person screen for the hero fact.

Map: how to get it grey

MapKit has no greyscale style. Muted dark is close: dark grey land, slightly lighter roads, and blue-black water. Two ways to finish the job.

OptionHowVerdict
A. MapKit muted dark plus desaturation.mapStyle(.standard(elevation: .flat, emphasis: .muted, pointsOfInterest: .excludingAll, showsTraffic: false)), force dark, then .grayscale(1) or .saturation(0) on the Map view.Try first, day one. Zero dependencies, Apple's own labels and roads. Whether SwiftUI's desaturation applies to a MapKit-backed view is unverified; I found no source either way. Fifteen minutes on device settles it.
B. MapKit muted dark, no filterSame style, skip the filter. Pins and the glass sheet carry the monochrome; water stays faintly blue.The fallback if A does nothing. Still clean, not strictly grey.
C. MapLibre Native with a monochrome vector styleMapLibre Native iOS via Swift Package Manager, Protomaps basemap in the "black" theme, tiles from the Protomaps API or a PMTiles file you host on spark.True greyscale, every colour yours, offline capable. Costs a dependency, a tile source, and losing Apple's map data. Only if A fails and B bothers you.
Recommendation: A, and let the on-device test decide between B and C. Do not start with C; it pulls a server into a project that otherwise has none.

Data

Four tables and a key-value row. Meetings are recomputed from visits and contact-add intervals unless the user set them.

person   contact_id TEXT PRIMARY KEY, name, initials, before_install BOOL, created_at

place    id INTEGER PK, key TEXT UNIQUE ('g:<placeID>' | 'c:<lat5>,<lon5>'), lat, lon, name?, named_at?
         INDEX(lat), INDEX(lon)                       -- viewport query is a lat/lon range; no R*Tree

visit    id INTEGER PK, place_id → place, start, end, source ('timeline'|'live'), accuracy_m
         INDEX(start), INDEX(end)

meet     contact_id TEXT PRIMARY KEY → person,
         start, end, precision ('exact'|'day'|'month'|'year'|'unknown'),
         place_id? → place, tier (0|1|2|3|NULL), user_set BOOL, add_seen_start?, add_seen_end?, computed_at

kv       key TEXT PRIMARY KEY, value BLOB            -- contacts history token, last tick, onboarding done

The resolver in six lines

tick():                                   runs on every launch, including background relaunch from a visit
  visits += VisitMonitor.flush()
  adds    = ContactsDiff.run(token)       -- CNChangeHistoryAddContactEvent since last tick
  for each add:  interval = [last_tick, now]
     v = visit containing interval          → meet(tier 1, place v, start/end = interval ∩ v)
     ?? nearest visit within 2h             → meet(tier 2)
     ?? none                                → meet(tier 3, date only)
  user_set rows are never touched

Cut from v0

  • Calendar, EventKit, attendee emails. Gone, and with it the handle table.
  • Sources tab. Folded into a settings sheet.
  • Unknown-tagging game. Replaced by "Set when you met" on the person screen.
  • HealthKit routes, Journal suggestions, Swift Charts, background processing tasks, R*Tree.
  • Photos and face matching. Later.
  • Mac companion, any server. Later or never.
